## ✨ Возможности

| | |
|---|---|
| 🎨 **Визуальный ввод** | Кликайте по наклейкам на развёртке-кресте. Наведите на любую — увидите её цвет. Центры заблокированы: они задают цвет грани. |
| ✅ **Живая проверка** | Мгновенная проверка количества цветов (по 9 каждого). Наведите на чип статуса — увидите столбчатую диаграмму по цветам. Чётность проверяет солвер. |
| ⚡ **Оптимальное решение** | [Двухфазный алгоритм Коцьембы](https://kociemba.org/cube.htm) — любой куб собирается за **≤ 20 ходов** меньше чем за секунду. |
| 🎞️ **Пошаговое выполнение** | Применяйте ходы по одному. Активная грань подсвечивается и **вращается в плоскости** к цели; наклейки меняются в середине поворота. Любой шаг можно отменить. |
| 🌍 **Два языка** | Русский / английский — определяется по локали ОС, переключается одним кликом, сохраняется в `localStorage`. |
| 💾 **Сохранение и обмен** | Храните состояния куба локально, переименовывайте их, экспортируйте и импортируйте всю коллекцию в JSON. |
| 🧭 **Понятные ходы** | Никаких загадочных `R U R'` — каждый шаг читается как *«Право: смотришь справа → крути по часовой ↻»*. |

## 🧠 Как это работает

Решатель построен на [**`cubejs`**](https://github.com/ldez/cubejs) — JavaScript-порте **двухфазного алгоритма** Герберта Коцьембы:

1. **Фаза 1** переводит куб в подгруппу `G₁ = ⟨U, D, R², L², F², B²⟩` — все рёбра и углы правильно *ориентированы*.
2. **Фаза 2** решает внутри `G₁`, используя только эти ограниченные повороты, до полностью собранного состояния.

Поиск — итеративно-углубляющийся A\* по предвычисленным таблицам отсечения, поэтому всегда возвращается последовательность **не длиннее 20 ходов** (диаметр группы куба в метрике полуоборотов — «число Бога»).

Состояние куба кодируется 54-символьной строкой **URFDLB** и проверяется структурно (по 9 каждого цвета, фиксированные центры) до решения — невозможный куб никогда не дойдёт до движка.

## 🛠️ Стек

| Слой | Выбор | Почему |
|---|---|---|
| Фреймворк | **Vue 3.5** `<script setup>` | Реактивный, минимальный, композируемый |
| Язык | **TypeScript 6** (strict) | Type-safe ключи i18n, размеченные объединения, `satisfies` |
| Сборка | **Vite 8** | Мгновенный HMR, компактный прод-бандл (~43 КБ gzip) |
| Солвер | **cubejs** | Двухфазный Коцьемба, ≤ 20 ходов |
| Качество | **ESLint 10** + typescript-eslint (strict, type-checked) | Политика нуля предупреждений |

## 📁 Структура проекта

```
src/
├─ types/cube.ts          # FaceLetter выводится из FACE_ORDER — единый источник правды
├─ i18n.ts                # type-safe переводы (ключи — объединение шаблонных литералов)
├─ lib/cubejs.ts          # единая документированная точка интеропа с солвером
├─ composables/
│  ├─ useCube.ts          # реактивное состояние куба + валидация (размеченное объединение)
│  ├─ useSolver.ts        # обёртка Коцьембы, реактивные шаги решения
│  └─ useSavedConfigs.ts  # хранение в localStorage + экспорт/импорт JSON
└─ components/
   ├─ FaceGrid.vue        # одна грань: покраска, тултипы, анимация вращения
   ├─ SolutionPanel.vue   # список шагов, прогресс, применение/отмена шага
   ├─ ValidationChip.vue  # чип статуса + диаграмма по цветам при наведении
   ├─ SavedConfigs.vue    # список сохранённых состояний
   └─ HeaderLinks.vue     # переключатель языка, ссылки, инфо об алгоритме
```
